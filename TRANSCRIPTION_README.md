# 📝 Транскрибация видео в HTML

## ⚠️ Проблема

Видео по указанной ссылке является **приватным** и защищено от скачивания. RuTube возвращает ошибку 403 Forbidden.

## ✅ Решения

### Вариант 1: Транскрибация локального файла (РЕКОМЕНДУЕТСЯ)

Если вы можете скачать видео вручную через браузер:

1. Откройте видео в браузере
2. Скачайте его через браузер (если доступна такая опция)
3. Запустите скрипт:

```bash
python3 transcribe_local_file.py /путь/к/скачанному/файлу.mp4
```

**Преимущества:**
- ✅ Не требует cookies
- ✅ Работает с любыми форматами видео/аудио
- ✅ Самый простой способ
- ✅ Красивый HTML с таймкодами

### Вариант 2: Использование cookies из браузера

Если видео доступно вам в браузере, но не скачивается:

#### Шаг 1: Экспорт cookies

**Для Chrome/Edge:**
1. Установите расширение [Get cookies.txt LOCALLY](https://chrome.google.com/webstore/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)
2. Откройте страницу с видео
3. Нажмите на иконку расширения
4. Нажмите "Export" и сохраните как `cookies.txt`

**Для Firefox:**
1. Установите расширение [cookies.txt](https://addons.mozilla.org/en-US/firefox/addon/cookies-txt/)
2. Откройте страницу с видео
3. Нажмите на иконку расширения
4. Сохраните как `cookies.txt`

#### Шаг 2: Поместите cookies.txt в текущую директорию

```bash
cp /путь/к/cookies.txt /home/user/ads/cookies.txt
```

#### Шаг 3: Запустите скрипт

```bash
python3 transcribe_with_cookies.py "https://rutube.ru/video/private/40128d8e76495245bd2ec70bda4b30bb/?p=d6tJR_LQzVg8_FdwZ0ZmnQ"
```

### Вариант 3: Использование инструментов браузера

1. Откройте видео в браузере
2. Нажмите F12 (Developer Tools)
3. Перейдите на вкладку Network
4. Найдите запрос к видео файлу (обычно .m3u8 или .mp4)
5. Скопируйте URL и попробуйте скачать напрямую:

```bash
yt-dlp --no-check-certificate "<скопированный_URL>"
```

## ⚙️ Настройки

Вы можете изменить следующие параметры в скриптах:

- `chunk_duration_ms` - длительность сегментов (по умолчанию 60000 мс = 1 минута)
- `language` - язык распознавания (по умолчанию "ru-RU")

## ❓ Часто задаваемые вопросы

**Q: Почему не работает прямое скачивание с RuTube?**
A: Видео является приватным и требует авторизации. Используйте cookies или скачайте вручную.

**Q: Как долго длится транскрибация?**
A: Зависит от длительности видео. Примерно 1-2 минуты на каждую минуту видео.

**Q: Можно ли использовать для других языков?**
A: Да, измените параметр `language="ru-RU"` на нужный (например, `"en-US"` для английского).

**Q: Что делать если речь не распознается?**
A: Убедитесь, что аудио качественное и громкость достаточная. Фоновый шум может мешать распознаванию.

## 🆘 Поддержка

Если возникли проблемы:
1. Проверьте, что файл существует и доступен
2. Убедитесь, что в файле есть аудио дорожка
3. Проверьте формат файла (должен быть видео или аудио)
4. Для приватных видео убедитесь, что cookies актуальны
