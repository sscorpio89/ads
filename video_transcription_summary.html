Краткое резюме: Бот для поиска и бронирования таймслотов на Озон

1. Назначение бота

Telegram-бот для автоматического поиска и бронирования таймслотов для поставок товаров на маркетплейс Озон. Актуальный инструмент для решения проблем с доступностью слотов.

2. Первоначальная настройка

2.1. Настройка кабинетов

  • Можно добавить до 5 кабинетов
  • Для каждого кабинета нужны: Seller ID и API ключ
Важное ограничение: Один кабинет = один Telegram аккаунт. Это ограничение Telegram, нельзя привязать один API ключ к нескольким аккаунтам.
Решение для команд: Создайте корпоративный Telegram аккаунт для работы, к которому будут иметь доступ все нужные сотрудники (собственник и менеджеры).

2.2. Генерация API ключа

  • Зайти в личный кабинет Озон → Настройки
  • Сгенерировать API ключ с ролью Order (именно эта роль обязательна)
  • Ввести Seller ID и API ключ в боте

3. Работа с поставками

3.1. Создание поставки

  • Поставка создается в личном кабинете Озон (не в боте)
  • Выбирается склад отгрузки и склад(ы) назначения (кластеры)
  • Поставка должна находиться в статусе "черновик"
  • Товарный состав должен быть согласован Озоном
Типы поставок:
  • Одна точка отгрузки → один склад назначения (быстрее находятся слоты)
  • Одна точка отгрузки → несколько складов назначения (сложнее найти слоты)

3.2. Настройка поиска в боте

  • Выбрать поставку из списка
  • Нажать "Отслеживать"
  • Выбрать до 5 таймслотов (дата + временной промежуток)
  • Можно выбрать:
    • Разные дни с разным временем
    • Один день с 5 разными временными промежутками
    • Любую комбинацию дат и времени

3.3. Процесс бронирования

  1. Бот начинает автоматически искать доступные слоты в заданных промежутках
  2. При нахождении слота бот его автоматически бронирует
  3. Приходит уведомление в Telegram о забронированном слоте
  4. За день до поставки приходит напоминание
  5. Слот отображается в личном кабинете Озон

4. Система бронирований

4.1. Как работает подписка

  • Приобретается определенное количество бронирований
  • Бронирование = забронированный слот (не поиск, а результат)
  • Если бот нашел и забронировал слот → списывается одно бронирование
  • Количество поисков неограничено, оплачивается только результат
Важно: Если создать 50 поставок и бот найдет слоты для всех 50 — спишется 50 бронирований. Будьте внимательны при создании множества поставок.

4.2. Срок действия

  • Неиспользованные бронирования сгорают в конце месяца
  • Можно докупить бронирования до окончания месяца — старые сохранятся (как минуты у оператора)
  • История сохраняется за вами

5. Управление поставками

5.1. Изменение параметров поиска

  • Можно в любой момент изменить даты и временные промежутки
  • Нажать "Редактировать" → выбрать новые таймслоты
  • Бот переключится на поиск в новых промежутках

5.2. Отмена отслеживания

  • Можно остановить отслеживание поставки
  • Нажать "Не отслеживать"

6. Важные ограничения и особенности

6.1. Технические ограничения

  • Один кабинет = один Telegram аккаунт (нельзя обойти)
  • Максимум 5 таймслотов для одной поставки (пока в тестовом режиме)
  • Нельзя искать на "любую дату" — нужно задать конкретные промежутки
  • Бот не может одновременно проверять все 24 часа в сутках
  • Бот работает только с поставками в статусе "черновик"

6.2. Логика работы бота

  • Бот последовательно проверяет заданные временные промежутки
  • Проходит по кругу все указанные слоты
  • Озон не дает возможности проверять все время сразу
  • Поэтому важно задавать конкретные промежутки, когда вам удобно

6.3. Ограничения по поставкам

  • Бот не создает поставки — только ищет слоты для существующих
  • Бот не может распределять товары по разным складам в кластере
  • Если Озон не принимает какие-то артикулы — нужно сначала решить это в ЛК
  • Бот не может автоматически переносить даты без указания, на какую дату переносить

7. Рекомендации по использованию

7.1. Для максимальной эффективности

  • Создавайте поставки с одним направлением (проще найти слот)
  • Указывайте несколько временных промежутков в разные дни
  • Не создавайте избыточное количество поставок (платите за каждое бронирование)

7.2. Для нескольких направлений в один день

  • Вариант 1: Создать одну поставку с несколькими направлениями
  • Вариант 2: Создать несколько поставок с одинаковыми таймслотами
  • Не гарантируется, что все направления найдутся одновременно

7.3. Тестирование

  • Экспериментируйте с разными подходами
  • Смотрите, где быстрее находятся слоты
  • Оптимизируйте процесс под свои задачи

8. Основной алгоритм работы

  1. В личном кабинете Озон: создать поставку в черновике
  2. В боте: выбрать поставку и нажать "Отслеживать"
  3. В боте: выбрать до 5 дат с временными промежутками
  4. Автоматически: бот ищет и бронирует доступный слот
  5. Уведомление: получить сообщение о бронировании
  6. В личном кабинете Озон: увидеть забронированный слот
  7. За день до поставки: получить напоминание

9. Частые вопросы из видео

Q: Можно ли привязать один кабинет к нескольким Telegram аккаунтам?

A: Нет, это ограничение Telegram. Решение — создать корпоративный аккаунт.

Q: Можно ли чтобы бот искал слоты на "любое ближайшее время"?

A: Нет, нужно задать конкретные временные промежутки. Без ТЗ (дата + время) бот не знает, что искать.

Q: Почему ограничение в 5 слотов?

A: Это тестовый режим. Если технически возможно, количество будет увеличено.

Q: Можно ли распределять товары по разным складам в кластере?

A: Нет, Озон не дает таких данных. Бот находит слот на любой доступный склад в кластере.

Q: Что если Озон принимает не все товары из поставки?

A: Бот работает только с поставками, где товарный состав уже согласован на финальной стадии.

Q: Можно ли автоматически переносить дату поставки?

A: Нет, нужно вручную изменить параметры поиска. Бот не знает, на какую дату переносить.

Итого

Бот — это инструмент для автоматизации поиска доступных таймслотов. Он не заменяет полностью ручную работу, но значительно экономит время, избавляя от необходимости постоянно обновлять страницу в личном кабинете. Требует настройки и понимания логики работы, но существенно упрощает процесс бронирования слотов на Озон.
