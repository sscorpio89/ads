## 🚀 Как использовать эти материалы

### Шаг 1: Регистрация на Ozon Seller
Зарегистрируйтесь на https://seller.ozon.ru/ и заполните профиль продавца

### Шаг 2: Подготовка фотографий
Организуйте фотосъёмку согласно `images-description.md` (разрешение минимум 1200x1200 px)

### Шаг 3: Создание карточки товара
1. Войдите в личный кабинет Ozon Seller
2. Перейдите в "Товары" → "Добавить товар"
3. Выберите категорию "Товары для дома" → "Вешалки и плечики"

### Шаг 4: Заполнение характеристик
Используйте данные из `characteristics.json` для заполнения всех полей

### Шаг 5: Написание описания
Скопируйте текст из `description.md`, адаптировав под формат Ozon

### Шаг 6: SEO-оптимизация
Используйте ключевые слова из `keywords-seo.txt` для названия и описания

### Шаг 7: Предпросмотр
Откройте `product-preview.html` в браузере для проверки карточки
