## 🚀 Как использовать эти материалы

### Шаг 1: Подготовка фотографий
1. Изучите файл `images-description.md`
2. Организуйте фотосъёмку согласно описаниям
3. Обработайте фото (разрешение минимум 1200x1200 px, формат JPG)

### Шаг 2: Регистрация на Ozon Seller
1. Зарегистрируйтесь на https://seller.ozon.ru/
2. Заполните информацию о продавце
3. Подключите необходимые категории товаров

### Шаг 3: Создание карточки товара
1. Войдите в личный кабинет Ozon Seller
2. Перейдите в раздел "Товары" → "Добавить товар"
3. Выберите категорию "Мебель" → "Табуреты"
4. Следуйте пошаговой инструкции в файле `ozon-upload-guide.md`

### Шаг 4: Заполнение характеристик
1. Откройте файл `characteristics.json`
2. Скопируйте данные в соответствующие поля на Ozon
3. Используйте описание из файла `description.md`

### Шаг 5: Загрузка фотографий
1. Загрузите все 8 фотографий в указанном порядке
2. Главное фото должно быть самым привлекательным

### Шаг 6: SEO-оптимизация
1. Используйте ключевые слова из файла `keywords-seo.txt`
2. Добавьте их в название и описание товара естественным образом

### Шаг 7: Предпросмотр
1. Откройте файл `product-preview.html` в браузере
2. Проверьте, как выглядит карточка
3. Внесите корректировки при необходимости
