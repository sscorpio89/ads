📊 Анализ рынка сервисов для работы с таймслотами Ozon

Цель исследования: Найти и проанализировать существующие веб-сервисы и Telegram-боты для автобронирования таймслотов Ozon, выявить их сильные и слабые стороны, а также определить возможности для создания конкурентного продукта.

Поток данных: Мониторинг слотов

1. Scheduler (Celery Beat)

Каждую минуту запускает задачу проверки слотов

2. Celery Worker

Получает список активных пользователей из PostgreSQL

3. Для каждого пользователя

Запрашивает доступные слоты через Ozon API

4. Сравнение с кешем

Проверяет Redis cache на наличие новых слотов

5. При нахождении новых слотов

Сохраняет в PostgreSQL и ставит в очередь уведомление

6. Notification Worker

Отправляет уведомление через Telegram API

🗄 Схема базы данных

PostgreSQL Tables

users

Поле Тип Описание
id BIGSERIAL PK Уникальный ID
telegram_id BIGINT UNIQUE ID пользователя в Telegram
ozon_client_id VARCHAR(255) Client ID от Ozon
ozon_api_key TEXT Зашифрованный API ключ
subscription_status VARCHAR(50) trial, active, expired
preferences JSONB Настройки пользователя
created_at TIMESTAMP Дата регистрации

slots

Поле Тип Описание
id BIGSERIAL PK Уникальный ID
user_id BIGINT FK Ссылка на пользователя
warehouse_id BIGINT ID склада
slot_datetime TIMESTAMP Дата и время слота
delivery_type VARCHAR(50) FBO, FBS, etc
found_at TIMESTAMP Когда найден
notified_at TIMESTAMP Когда отправлено уведомление

subscriptions

Поле Тип Описание
id BIGSERIAL PK Уникальный ID
user_id BIGINT FK Ссылка на пользователя
plan VARCHAR(50) free, standard, pro, business
status VARCHAR(50) pending, active, expired
started_at TIMESTAMP Начало подписки
expires_at TIMESTAMP Окончание подписки

Redis Schema

# User slot cache (TTL: 5 minutes)
slots:{user_id} → JSON array

# FSM states
fsm:{telegram_id}:state → state name
fsm:{telegram_id}:data → JSON data

# Rate limiting
rate_limit:api:{api_key}:{minute} → count (TTL: 60s)
rate_limit:ozon:{user_id}:{minute} → count (TTL: 60s)

# Ozon API cache (TTL: 10 minutes)
ozon:warehouses → JSON array
ozon:user:{user_id}:profile → JSON

# Task locks
lock:monitor:{user_id} → lock flag

# Analytics counters
stats:daily:{date}:new_users → counter
stats:daily:{date}:notifications_sent → counter

  • 70%+ retention
  • 20%+ конверсия в платную подписку
  • NPS > 40
6 месяцев
  • 500+ платящих пользователей
  • Выход в прибыль
  • LTV > 5000₽
  • CAC < 1000₽
Через год
  • 2000+ платящих пользователей
  • 2+ маркетплейса
  • Команда 3-5 человек
  • Масштабируемая инфраструктура

🚀 План MVP

Срок разработки: 4-6 недель
Стоимость инфраструктуры: ~100€ на 3 месяца
Подход: Бот-монитор БЕЗ автобронирования (безопасно)

Почему без автобронирования?

  • ✅ Безопасно - не нарушает правила маркетплейса
  • ✅ Низкий риск блокировки пользователей
  • ✅ Проще разработка и тестирование
  • ✅ Меньше юридических рисков
  • ✅ Быстрее выход на рынок

Функционал MVP

1. Регистрация и настройка (Неделя 1)

  • Регистрация через Telegram бота
  • Подключение магазина Ozon (Client-ID, API-Key)
  • Валидация API ключей
  • Хранение настроек пользователя

2. Мониторинг слотов (Неделя 2-3)

  • Проверка доступных слотов каждую 1-5 минут
  • Выбор складов для мониторинга
  • Фильтрация по типу поставки (FBO)
  • Отображение деталей найденных слотов

3. Уведомления (Неделя 3)

  • Мгновенные push-уведомления в Telegram
  • Настройка "тихих часов"
  • Кнопка "Забронировать на Ozon" (deep link)

4. Базовая аналитика (Неделя 4)

  • История найденных слотов
  • Статистика по складам
  • Команда /stats

5. Подписка (Неделя 4-5)

  • Telegram Stars для оплаты
  • Бесплатный пробный период 7 дней
  • Подписка: 500-700 Stars/месяц (~900₽)

Не просто "бот для слотов", а комплексное решение для оптимизации логистики на маркетплейсах с постепенным добавлением функций на основе обратной связи пользователей.
