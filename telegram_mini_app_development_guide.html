1. Введение в Telegram Mini Apps

Telegram Mini Apps (ранее Web Apps) — это веб-приложения, которые запускаются внутри Telegram мессенджера и имеют доступ к специальному JavaScript API для взаимодействия с платформой Telegram.

1.1. Что такое Telegram Mini App?

  • Веб-приложение — работает как обычный сайт (HTML/CSS/JavaScript)
  • Встроенный в Telegram — открывается прямо в мессенджере без внешнего браузера
  • Доступ к Telegram API — через window.Telegram.WebApp
  • Нативный UI — кнопки, темы, жесты интегрированы с Telegram
  • Аутентификация — пользователь уже авторизован через Telegram

1.2. Преимущества Mini App для нашего проекта

  • ✅ Богатый UI: Полноценный интерфейс с формами, таблицами, графиками
  • ✅ Быстрая разработка: Используем React/Vue/любой фреймворк
  • ✅ Нет установки: Пользователь просто открывает бота
  • ✅ Встроенные платежи: Telegram Payments API
  • ✅ Кроссплатформенность: iOS, Android, Desktop, Web
  • ✅ Обновления: Мгновенное обновление без App Store

3. Настройка бота через BotFather

Шаг 1: Создание бота

  1. Откройте Telegram и найдите @BotFather
  2. Отправьте команду /newbot
  3. Введите имя бота: Ozon Slot Booking
  4. Введите username: your_slot_bot
  5. Сохраните полученный BOT_TOKEN

Шаг 2: Настройка Mini App

  1. Отправьте BotFather команду /newapp
  2. Выберите созданного бота
  3. Введите название Mini App: Ozon Slots
  4. Введите описание: Автоматическое бронирование слотов для поставок на Ozon
  5. Загрузите иконку 640x360 (PNG)
  6. Загрузите GIF демонстрацию (опционально)
  7. Введите Web App URL: https://your-domain.com/miniapp

⚠️ Важно:

  • URL должен быть HTTPS (обязательно!)
  • Домен должен быть уже доступен на момент создания
  • Для разработки можно использовать ngrok или локальный HTTPS

Шаг 3: Настройка команд бота

Отправьте BotFather команду /setcommands и введите:

start - Открыть главную страницу
help - Помощь по использованию
balance - Показать баланс бронирований
stores - Мои кабинеты OZON
supplies - Мои поставки
tariffs - Тарифы и оплата
support - Техническая поддержка

Шаг 4: Настройка меню кнопки

Отправьте BotFather команду /setmenubutton:

  • Button text: Открыть приложение
  • URL: https://your-domain.com/miniapp

4.3. Интеграция Telegram WebApp SDK

src/hooks/useTelegram.ts:

import { useEffect, useState } from 'react';
import WebApp from '@twa-dev/sdk';

export const useTelegram = () => {
  const [user, setUser] = useState(WebApp.initDataUnsafe?.user);
  const [initData, setInitData] = useState(WebApp.initData);

  useEffect(() => {
    // Готовность приложения
    WebApp.ready();

    // Расширяем на весь экран
    WebApp.expand();

    // Применяем тему Telegram
    document.body.style.backgroundColor = WebApp.backgroundColor;

    // Слушаем изменения темы
    WebApp.onEvent('themeChanged', () => {
      document.body.style.backgroundColor = WebApp.backgroundColor;
    });

    return () => {
      WebApp.offEvent('themeChanged');
    };
  }, []);

  // Закрыть Mini App
  const close = () => {
    WebApp.close();
  };

  // Показать главную кнопку
  const showMainButton = (text: string, onClick: () => void) => {
    WebApp.MainButton.setText(text);
    WebApp.MainButton.show();
    WebApp.MainButton.onClick(onClick);
  };

  // Скрыть главную кнопку
  const hideMainButton = () => {
    WebApp.MainButton.hide();
  };

  // Показать кнопку "Назад"
  const showBackButton = (onClick: () => void) => {
    WebApp.BackButton.show();
    WebApp.BackButton.onClick(onClick);
  };

  // Скрыть кнопку "Назад"
  const hideBackButton = () => {
    WebApp.BackButton.hide();
  };

  // Тактильная обратная связь
  const hapticFeedback = (type: 'light' | 'medium' | 'heavy' | 'error' | 'success' | 'warning') => {
    if (type === 'light' || type === 'medium' || type === 'heavy') {
      WebApp.HapticFeedback.impactOccurred(type);
    } else {
      WebApp.HapticFeedback.notificationOccurred(type as any);
    }
  };

  // Открыть ссылку
  const openLink = (url: string) => {
    WebApp.openLink(url);
  };

  // Показать всплывающее окно
  const showPopup = (params: {
    title: string;
    message: string;
    buttons: Array<{ id: string; type?: 'default' | 'ok' | 'close' | 'cancel' | 'destructive'; text: string }>;
  }) => {
    return new Promise((resolve) => {
      WebApp.showPopup(params, (buttonId) => {
        resolve(buttonId);
      });
    });
  };

  // Показать подтверждение
  const showConfirm = (message: string) => {
    return new Promise((resolve) => {
      WebApp.showConfirm(message, (confirmed) => {
        resolve(confirmed);
      });
    });
  };

  // Проверка, запущено ли внутри Telegram
  const isInTelegram = WebApp.initData !== '';

  return {
    user,
    initData,
    isInTelegram,
    theme: WebApp.themeParams,
    platform: WebApp.platform,
    version: WebApp.version,
    close,
    showMainButton,
    hideMainButton,
    showBackButton,
    hideBackButton,
    hapticFeedback,
    openLink,
    showPopup,
    showConfirm,
  };
};

4.4. API клиент

src/services/api.ts:

import axios from 'axios';
import WebApp from '@twa-dev/sdk';

const API_BASE_URL = import.meta.env.VITE_API_BASE_URL || 'https://your-api.com';

// Создаем axios инстанс
const api = axios.create({
  baseURL: API_BASE_URL,
  timeout: 30000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// Interceptor для добавления Telegram initData
api.interceptors.request.use((config) => {
  const initData = WebApp.initData;
  if (initData) {
    config.headers['X-Telegram-Init-Data'] = initData;
  }
  return config;
});

// Interceptor для обработки ошибок
api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      WebApp.showAlert('Ошибка аутентификации. Перезапустите приложение.');
    }
    return Promise.reject(error);
  }
);

export default api;

5.3. Валидация Telegram initData

backend/app/core/security.py:

import hashlib
import hmac
from urllib.parse import parse_qsl
from typing import Dict, Optional
from fastapi import HTTPException, Header
from app.core.config import settings

def validate_telegram_init_data(init_data: str) -> Dict[str, any]:
    """
    Валидирует initData от Telegram WebApp
    Документация: https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app
    """
    try:
        # Парсим query string
        parsed_data = dict(parse_qsl(init_data))

        # Извлекаем hash
        received_hash = parsed_data.pop('hash', None)
        if not received_hash:
            raise HTTPException(status_code=401, detail="Missing hash")

        # Создаем data-check-string
        data_check_arr = [f"{k}={v}" for k, v in sorted(parsed_data.items())]
        data_check_string = '\n'.join(data_check_arr)

        # Вычисляем secret_key
        secret_key = hmac.new(
            key=b"WebAppData",
            msg=settings.BOT_TOKEN.encode(),
            digestmod=hashlib.sha256
        ).digest()

        # Вычисляем hash
        calculated_hash = hmac.new(
            key=secret_key,
            msg=data_check_string.encode(),
            digestmod=hashlib.sha256
        ).hexdigest()

        # Сравниваем
        if not hmac.compare_digest(received_hash, calculated_hash):
            raise HTTPException(status_code=401, detail="Invalid hash")

        # Проверяем auth_date (не старше 24 часов)
        import time
        auth_date = int(parsed_data.get('auth_date', 0))
        if abs(time.time() - auth_date) > 86400:  # 24 часа
            raise HTTPException(status_code=401, detail="Data is outdated")

        # Парсим user данные
        import json
        user_data = json.loads(parsed_data.get('user', '{}'))

        return {
            'user_id': user_data.get('id'),
            'username': user_data.get('username'),
            'first_name': user_data.get('first_name'),
            'last_name': user_data.get('last_name'),
            'language_code': user_data.get('language_code'),
            'auth_date': auth_date,
        }

    except Exception as e:
        raise HTTPException(status_code=401, detail=f"Invalid initData: {str(e)}")

async def get_current_user(
    x_telegram_init_data: Optional[str] = Header(None)
) -> Dict[str, any]:
    """
    Dependency для получения текущего пользователя из Telegram initData
    """
    if not x_telegram_init_data:
        raise HTTPException(status_code=401, detail="Missing Telegram initData")

    return validate_telegram_init_data(x_telegram_init_data)

from app import models, schemas
from app.services.ozon import validate_ozon_credentials
from app.core.encryption import encrypt_api_key, decrypt_api_key

router = APIRouter()

@router.get("/", response_model=List[schemas.Store])
async def get_stores(
    current_user: dict = Depends(get_current_user),
    db: AsyncSession = Depends(get_db)
):
    """Получить список магазинов пользователя"""
    result = await db.execute(
        select(models.Store).where(models.Store.user_id == current_user['user_id'])
    )
    stores = result.scalars().all()
    return stores

@router.post("/", response_model=schemas.Store)
async def create_store(
    store_data: schemas.StoreCreate,
    current_user: dict = Depends(get_current_user),
    db: AsyncSession = Depends(get_db)
):
    """Добавить новый магазин"""
    # Проверяем лимит (максимум 5)
    result = await db.execute(
        select(func.count(models.Store.id)).where(
            models.Store.user_id == current_user['user_id']
        )
    )
    count = result.scalar()
    if count >= 5:
        raise HTTPException(status_code=400, detail="Максимум 5 магазинов")

    # Валидируем ключи через Ozon API
    is_valid = await validate_ozon_credentials(
        store_data.client_id,
        store_data.api_key
    )

    if not is_valid:
        raise HTTPException(status_code=400, detail="Невалидные API ключи")

    # Шифруем API key
    encrypted_key = encrypt_api_key(store_data.api_key)

    # Создаем магазин
    store = models.Store(
        user_id=current_user['user_id'],
        title=store_data.title,
        client_id=store_data.client_id,
        api_key_encrypted=encrypted_key,
        status='VALID'
    )

    db.add(store)
    await db.commit()
    await db.refresh(store)

    return store

@router.delete("/{store_id}")
async def delete_store(
    store_id: int,
    current_user: dict = Depends(get_current_user),
    db: AsyncSession = Depends(get_db)
):
    """Удалить магазин"""
    result = await db.execute(
        select(models.Store).where(
            models.Store.id == store_id,
            models.Store.user_id == current_user['user_id']
        )
    )
    store = result.scalar_one_or_none()

    if not store:
        raise HTTPException(status_code=404, detail="Магазин не найден")

    await db.delete(store)
    await db.commit()

    return {"message": "Магазин удален"}

7. Интеграция с Ozon Seller API

7.1. Ozon API клиент

backend/app/services/ozon.py:

import aiohttp
from typing import List, Dict, Optional
from app.core.config import settings

class OzonAPI:
    BASE_URL = "https://api-seller.ozon.ru"

    def __init__(self, client_id: str, api_key: str):
        self.client_id = client_id
        self.api_key = api_key
        self.session = None

    async def __aenter__(self):
        self.session = aiohttp.ClientSession(
            headers={
                "Client-Id": self.client_id,
                "Api-Key": self.api_key,
                "Content-Type": "application/json",
            }
        )
        return self

    async def __aexit__(self, exc_type, exc_val, exc_tb):
        if self.session:
            await self.session.close()

    async def validate_credentials(self) -> bool:
        """Проверка валидности API ключей"""
        try:
            async with self.session.post(
                f"{self.BASE_URL}/v1/roles",
                json={}
            ) as response:
                return response.status == 200
        except Exception:
            return False

    async def get_supply_orders(
        self,
        limit: int = 100,
        offset: int = 0,
        status: Optional[str] = None
    ) -> List[Dict]:
        """Получить список поставок"""
        payload = {
            "limit": limit,
            "offset": offset,
        }

        if status:
            payload["status"] = status

        async with self.session.post(
            f"{self.BASE_URL}/v3/supply-order/list",
            json=payload
        ) as response:
            data = await response.json()
            return data.get("result", {}).get("supply_orders", [])

    async def get_available_timeslots(
        self,
        warehouse_id: int,
        delivery_type: str = "fbo"
    ) -> List[Dict]:
        """Получить доступные таймслоты"""
        async with self.session.post(
            f"{self.BASE_URL}/v1/draft/timeslot/info",
            json={
                "warehouse_id": warehouse_id,
                "delivery_type": delivery_type
            }
        ) as response:
            data = await response.json()
            return data.get("result", {}).get("timeslots", [])

    async def update_timeslot(
        self,
        supply_order_id: str,
        timeslot_id: str
    ) -> bool:
        """Обновить (забронировать) таймслот"""
        try:
            async with self.session.post(
                f"{self.BASE_URL}/v1/supply-order/timeslot/update",
                json={
                    "supply_order_id": supply_order_id,
                    "timeslot_id": timeslot_id
                }
            ) as response:
                return response.status == 200
        except Exception:
            return False

async def validate_ozon_credentials(client_id: str, api_key: str) -> bool:
    """Валидация Ozon API ключей"""
    async with OzonAPI(client_id, api_key) as ozon:
        return await ozon.validate_credentials()

7.2. Celery задача для проверки слотов

backend/app/tasks/slot_checker.py:

from celery import Celery
from app.services.ozon import OzonAPI
from app.core.encryption import decrypt_api_key
from app.db.session import AsyncSessionLocal
from app import models
import asyncio

celery_app = Celery('tasks', broker='redis://localhost:6379/0')

@celery_app.task
def check_slots_for_order(order_id: int):
    """Проверить слоты для заказа"""
    asyncio.run(_check_slots_async(order_id))

async def _check_slots_async(order_id: int):
    async with AsyncSessionLocal() as db:
        # Получаем заказ
        order = await db.get(models.SupplyOrder, order_id)
        if not order or order.state != 'SEARCHING':
            return

        # Получаем магазин
        store = await db.get(models.Store, order.store_id)
        if not store or store.status != 'VALID':
            return

        # Получаем пользователя
        user = await db.get(models.User, store.user_id)
        if not user or user.balance_count <= 0:
            return

        # Получаем предпочтительные слоты
        result = await db.execute(
            select(models.TimeSlotPreference)
            .where(models.TimeSlotPreference.order_id == order_id)
            .order_by(models.TimeSlotPreference.priority)
        )
        preferences = result.scalars().all()

        # Расшифровываем API key
        api_key = decrypt_api_key(store.api_key_encrypted)

        # Проверяем доступность слотов
        async with OzonAPI(store.client_id, api_key) as ozon:
            available_slots = await ozon.get_available_timeslots(
                warehouse_id=order.warehouse_to_id
            )

            # Ищем подходящий слот
            for pref in preferences:
                for slot in available_slots:
                    if _matches_preference(slot, pref):
                        # Бронируем
                        success = await ozon.update_timeslot(
                            supply_order_id=order.ozon_supply_order_id,
                            timeslot_id=slot['id']
                        )

                        if success:
                            # Обновляем заказ
                            order.state = 'FOUND'
                            order.tracking_enabled = False
                            order.booked_at = datetime.utcnow()
                            order.booked_slot = slot

                            # Списываем бронирование
                            user.balance_count -= 1

                            await db.commit()

                            # Отправляем уведомление
                            from app.services.telegram import send_booking_notification
                            await send_booking_notification(user.telegram_user_id, order, slot)

                            return

def _matches_preference(slot: Dict, preference: models.TimeSlotPreference) -> bool:
    """Проверить соответствие слота предпочтениям"""
    # Здесь логика сравнения времени слота с предпочтениями
    # Упрощенная версия
    slot_date = datetime.fromisoformat(slot['from'])
    return (
        slot_date.date() == preference.date and
        slot_date.hour >= preference.hour_from and
        slot_date.hour < preference.hour_to
    )

# Настраиваем периодическую задачу
celery_app.conf.beat_schedule = {
    'check-slots-every-5-minutes': {
        'task': 'app.tasks.slot_checker.check_all_active_orders',
        'schedule': 300.0,  # 5 минут
    },
}

from cryptography.fernet import Fernet
from app.core.config import settings

# Генерируем ключ шифрования (сохраняем в .env)
# key = Fernet.generate_key()

cipher_suite = Fernet(settings.ENCRYPTION_KEY.encode())

def encrypt_api_key(api_key: str) -> str:
    """Шифрование API ключа"""
    encrypted = cipher_suite.encrypt(api_key.encode())
    return encrypted.decode()

def decrypt_api_key(encrypted_key: str) -> str:
    """Расшифровка API ключа"""
    decrypted = cipher_suite.decrypt(encrypted_key.encode())
    return decrypted.decode()

9.2. Rate limiting

from fastapi import HTTPException
from redis import Redis
import time

redis_client = Redis(host='localhost', port=6379, db=0)

async def rate_limit(user_id: int, limit: int = 100, window: int = 60):
    """
    Rate limiting: максимум {limit} запросов за {window} секунд
    """
    key = f"rate_limit:{user_id}"
    current = redis_client.get(key)

    if current is None:
        redis_client.setex(key, window, 1)
        return

    if int(current) >= limit:
        raise HTTPException(
            status_code=429,
            detail="Too many requests. Please try again later."
        )

    redis_client.incr(key)
